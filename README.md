# 🌐 LingoLink AI

Enterprise-grade AI translation platform for voice, text, and video.

## 🚀 Features

- Real-time text translation
- Speech-to-text with Whisper AI
- Voice translation
- Web and mobile interfaces
- PostgreSQL database with Docker
- Redis for caching and queues

## 🛠️ Tech Stack

- **Backend:** Python, FastAPI, PyTorch, ONNX Runtime
- **Frontend:** React
- **Mobile:** Flutter
- **Database:** PostgreSQL (Docker)
- **Cache:** Redis (Docker)
- **AI Models:** OpenAI Whisper, Google Translator
- **Media Processing:** FFmpeg
